## What's new in v1.4

### Installation
- Added a native macOS PKG installer for easier installation and upgrades.
- The installer places OSD Editor directly into Applications.
- Retained the portable ZIP download as an alternative.
- Updated the application version and build metadata.

### Packaging
- Added automatic installer generation to the release build process.
- Included installer checksums alongside the ZIP downloads.
- Preserved the existing application icon, licensing information and ad-hoc signing.

### Existing functionality
- All v1.3 telemetry editing, presets, OSD customisation and export features remain available.

## Download and install

**Recommended:** Download `OSD-Editor-1.4-arm64.pkg`, open it and follow the installer.

**Alternative:** Download `OSD-Editor-1.4-Mac.zip`, extract it and copy `OSD Editor.app` into Applications.

Quit OSD Editor before upgrading. Existing fonts, settings and presets are stored separately from the application.

## Requirements

- Apple Silicon Mac
- macOS 27.0 or later
- Compatible OSD PNG font for graphical OSD editing
- No Homebrew, Xcode or separate FFmpeg installation required

The application is ad-hoc signed, not Apple-notarised. macOS may display a security warning.
