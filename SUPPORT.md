## v1.3.0 help

See the [user guide](docs/USER_GUIDE.md), [release notes](RELEASE_NOTES.md) and [installation guide](docs/INSTALLATION.md). For telemetry issues report the layer (T1/T2/etc.), SRT format, any timing offset and expected field/value. For presets describe the import order and aspect ratio. For voltage issues include a sanitised raw SRT excerpt with the expected SBat/GBat reading. Avoid sharing private footage or location data publicly.
