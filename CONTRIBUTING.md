# Contributing

Thank you for helping test or improve OSD Editor.

- Use the bug and compatibility templates for reproducible reports.
- Read docs/COMPATIBILITY.md before claiming support for another system.
- Keep source media unchanged and preserve exact input frame timing in export changes.
- Do not commit recordings, personal presets/settings, downloaded third-party fonts, credentials or generated builds.
- Build and run applicable checks using docs/BUILDING.md. UI changes also need manual checks at normal and full-screen window sizes.
- Contributions must be compatible with GPL-3.0-or-later. Preserve upstream notices and identify adapted work. Describe third-party dependencies/assets and their licences.
- Send a focused pull request explaining the problem, resulting behaviour and validation.

Feature requests and documentation improvements are welcome. Sample files can contain sensitive telemetry; use public issues to agree on what is needed before sharing any recording.
